* 1. Health

当 Evidence 启用时, =/api/v1/runtime/health= 额外返回:

- submitted_total.
- processed_total.
- dropped_total.
- errors_total.
- queue depth/capacity.
- drop_ratio.
- artifact_count.
- protected_count.
- total/max bytes.
- over_capacity.

* 3. 低开销容量状态

Retention status 默认最多每 60 秒重新扫描一次证据目录. Cleanup 执行后立即刷新缓存.

因此 Prometheus 高频抓取不会每次递归扫描 evidence root.

* 4. 72h Gate

新增默认门槛:

- evidence drop ratio <= 20%.
- evidence worker errors = 0.
- evidence over-capacity = false.

如果 Evidence 未启用, 不应用这些门槛.
