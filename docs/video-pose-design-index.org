* 12. Architecture Decisions

** ADR-001: AI facts, deterministic compliance

模型输出事实. 规则引擎输出最终合规结论.

** ADR-002: Four views share one time axis

四个摄像头不能作为四套独立判断.

** ADR-003: UNKNOWN is valid

不可观测和低置信度不能被自动变成 PASS.

** ADR-004: Persistent cameras and models

RTSP 和重模型跨 Session 常驻.

** ADR-005: Session state is isolated

Rule/Action state 每个 Session 单独创建.

** ADR-006: Explicit timestamp semantics

arrival, PTS, RFC7273 reference 必须显式配置和审计.

** ADR-007: Evidence First

Violation 必须可回到四路证据.

** ADR-008: Immutable Audit is source of recovery truth

SQL 是可重建 Query Store.

** ADR-009: Connectivity and completeness are separate

DB 可连接不代表 SQL 历史已补齐.

** ADR-010: Readiness gates formal Session start

process alive 不等于生产 Ready.

** ADR-011: Observability failure invalidates PASS

camera/sync/processing/evidence/audit 持续故障进入 SYSTEM_QUALITY.

** ADR-012: Crash recovery is explicit ABORTED

缺 final.json 的 Session 通过受控恢复追加 SYSTEM-QUALITY-RECOVERY.

* 14. Design Change Rule

以下变化必须同步设计文档:

- C4 Container boundary.
- timestamp source.
- Session lifecycle.
- ActionEvent schema.
- Rule semantics.
- SYSTEM_QUALITY semantics.
- Evidence identity/lifecycle.
- Audit/recovery contract.
- SQL schema.
- RBAC/API.
- Readiness Gate.
- Go/No-Go acceptance.

重大变化应增加或更新 ADR.
