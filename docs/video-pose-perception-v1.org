* 3. Detector 与 Pose Adapter

YOLO adapter 使用稳定的 Results.boxes 接口.

RTMPose adapter 使用 MMPose 1.x 的 =init_model + inference_topdown=.

模型权重和具体版本不进入业务层.

* 5. Human-Object Relation Builder

输入:

- OBJECT bbox.
- left_wrist/right_wrist keypoint.
- confidence.
- temporal history.

输出:

- NEAR.
- HELD_BY.
- FREE.

当前 baseline 使用 wrist 到 object bbox 的距离并进行连续帧 debounce.

它不是最终 HOI 模型, 但提供两个重要价值:

1. 在少量数据阶段形成可运行闭环.
2. 作为后续 learned Human-Object Interaction 模型的可解释 baseline.

* 6. Zone Builder

MVP 支持图像空间矩形 Zone.

用于快速验证:

- 工具架.
- 工件料框.
- 装配区域.
- 禁止区域.

正式多摄像头部署应逐步迁移到 C03 Pose Fusion 的 World Coordinate Zone.
