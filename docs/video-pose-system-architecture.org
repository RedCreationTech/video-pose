* 1. 系统概述

本系统用于通过多摄像头视频分析持续检测人员动作规范性。

核心目标:

- 通过前后左右四路摄像头采集操作过程
- 对人员姿态, 手部动作, 工具和对象进行识别
- 根据标准作业流程判断动作是否符合规范
- 自动生成评分, 异常记录和复盘视频

系统定位:

#+BEGIN_SRC text
Video Input
    |
Pose Understanding
    |
Action Understanding
    |
Process Compliance Engine
    |
Quality Assessment
#+END_SRC

* 4. C4 Level 3: Component Design

** Video Gateway

职责:

- RTSP/ONVIF摄像头连接
- 视频流管理
- 时间同步
- 视频缓存

技术:

- FFmpeg
- GStreamer
- WebRTC

** AI Perception Service

负责基础视觉理解。

组件:

*** Person Detector

技术:

- YOLO

输出:

#+BEGIN_SRC json
{
 "person_id": "001",
 "bbox": [100,200,300,500],
 "confidence":0.98
}
#+END_SRC

*** Pose Estimation

输出人体关键点。

推荐:

- RTMPose
- MediaPipe Pose

*** Object Detection

识别:

- 工具
- 零件
- 设备

** Pose Engine

负责:

- 多摄像头融合
- 2D到3D姿态转换
- 时间序列平滑

算法:

- VideoPose3D
- Transformer Pose Model

输入:

#+BEGIN_SRC text
Camera Frames
    |
2D Keypoints
    |
3D Skeleton
#+END_SRC

** Action Recognition Service

负责动作理解。

例如:

#+BEGIN_SRC text
Pick Tool
    |
Move Tool
    |
Install Part
    |
Check Result
#+END_SRC

技术:

- Video Transformer
- SlowFast
- Temporal CNN

** Rule Engine

工业场景不直接依赖AI判断。

采用:

AI识别 + 工艺规则。

规则模型:

#+BEGIN_SRC json
{
 "operation":"assembly",
 "steps":[
  {
   "action":"pick",
   "object":"screwdriver"
  },
  {
   "action":"install"
  }
 ]
}
#+END_SRC

** Evaluation Service

输出:

- 操作评分
- 异常类型
- 视频片段
- 改进建议
