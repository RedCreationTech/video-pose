* 1. 当前自动规则

Rule Engine 当前内建:

- MISSING.
- ORDER.
- TEMPORAL.

业务 YAML 规则继续负责:

- WRONG_TOOL.
- WRONG_OBJECT.
- SPATIAL.
- SAFETY 等.

* 2. ORDER

当事件匹配 PENDING 步骤, 但 predecessor 未完成:

#+BEGIN_SRC text
AUTO-ORDER-Sxxx
#+END_SRC

记录一次 ORDER 违规, 步骤仍可后续按正确顺序完成.

* 3. TEMPORAL

StepDefinition 支持:

#+BEGIN_SRC yaml
min_duration_ms: 500
max_duration_ms: 2000
temporal_severity: MINOR
#+END_SRC

动作时长来自:

#+BEGIN_SRC text
ended_at_ms - started_at_ms
#+END_SRC

超出区间产生:

#+BEGIN_SRC text
AUTO-TEMPORAL-Sxxx
type=TEMPORAL
#+END_SRC

步骤仍标记 COMPLETED, 因为动作确实发生了.

* 4. duration unavailable

当步骤配置了时长约束, 但 ActionEvent 没有 =ended_at_ms=, 当前视为 TEMPORAL 证据不足:

#+BEGIN_SRC text
reason=duration_unavailable
#+END_SRC

后续可以升级为 UNKNOWN/人工复核策略.
