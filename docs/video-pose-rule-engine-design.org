* 1. 核心职责

Rule Engine 消费 ActionEvent, 执行:

- SOP 状态推进.
- 顺序规则.
- 工具/对象规则.
- 空间规则.
- Missing Step.
- UNKNOWN.
- Violation.
- Score.

* 2. 顺序违规

当事件无法匹配任何 READY/ACTIVE 步骤时, 引擎继续检查 PENDING 步骤.

若事件:

- action 匹配.
- object/zone 约束匹配.
- confidence 达标.
- 但 predecessor 未完成.

则立即产生:

#+BEGIN_SRC text
AUTO-ORDER-<step>
type=ORDER
severity=MAJOR
#+END_SRC

步骤本身保持 PENDING, 不会因为一次提前操作被永久锁死.

因此现场可以出现:

#+BEGIN_SRC text
错误:
PLACE part before PICK

记录 ORDER

随后:
PICK part
PLACE part

步骤最终 COMPLETED
但 Session 保留 ORDER violation
#+END_SRC

* 3. Missing 与 Order 的区别

ORDER 表示动作发生了, 但时机错误.

MISSING 表示直到 Session 结束仍没有完成要求步骤.

系统不再用 MISSING 替代所有顺序问题.

* 4. 幂等

同一 PENDING step 默认只自动记录一次 ORDER violation, 避免连续视频帧重复扣分.

ActionEvent 本身继续使用 event_id/sequence 去重.

* 5. 后续

- minimum/maximum duration.
