* 1. 自动规则类型

当前内建:

- ORDER.
- TEMPORAL.
- TIMEOUT.
- MISSING.

业务规则继续负责:

- WRONG_TOOL.
- WRONG_OBJECT.
- SPATIAL.
- SAFETY.

* 2. 动作持续时间

Step 支持:

#+BEGIN_SRC yaml
min_duration_ms: 500
max_duration_ms: 2000
temporal_severity: MINOR
#+END_SRC

超出范围记录 TEMPORAL, 步骤仍 COMPLETED.

* 3. 步骤启动节拍

有 predecessor 的步骤可以配置:

#+BEGIN_SRC yaml
min_start_delay_ms: 100
max_start_delay_ms: 1000
start_delay_severity: MINOR
timeout_severity: MAJOR
#+END_SRC

=ready_at_ms= 取所有 predecessor 完成时间的最大值.

启动过早:

#+BEGIN_SRC text
TEMPORAL
reason=started_too_soon
#+END_SRC

超过最大等待窗口:

#+BEGIN_SRC text
TIMEOUT
#+END_SRC

如果迟到动作后来发生, 步骤仍 COMPLETED, 但保留 TIMEOUT.

* 4. Session End Timeout

RuleEngine.evaluate 支持:

#+BEGIN_SRC python
evaluate(events, session_end_ms=...)
#+END_SRC

当某步骤已经 READY, 但到 Session 结束仍未开始并超过 max_start_delay_ms:

- 记录 TIMEOUT.
- 步骤标记 VIOLATED.
- 不再重复记录 MISSING.

离线分析使用最后一个同步 FrameSet 时间作为 session_end_ms.

* 5. ORDER 与 TIMEOUT

ORDER:

动作发生在 predecessor 完成之前.

TIMEOUT:

predecessor 已完成, 但后续动作开始太晚或根本没开始.

两者语义分离.
