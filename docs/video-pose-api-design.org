* 1. 文档目标

本文定义 Video Pose 平台对外 API 和内部服务通信契约.

原则:

- 外部管理接口使用 REST/JSON.
- 实时 UI 使用 WebSocket 或 Server-Sent Events.
- 高吞吐内部推理链路使用 gRPC 或事件总线.
- 所有协议显式版本化.
- 所有写接口支持 trace_id.
- 关键写操作支持 idempotency key.

* 14. Internal gRPC

建议服务:

#+BEGIN_SRC text
VideoFrameService
PerceptionService
PoseFusionService
ActionRecognitionService
RuleEngineService
EvidenceService
#+END_SRC

Frame 不建议通过通用 JSON 传输.

在同一边缘节点可使用:

- shared memory.
- GStreamer pipeline.
- CUDA zero-copy.
- gRPC 只传元数据和控制消息.

* 15. Event Bus Contract

统一 envelope:

#+BEGIN_SRC json
{
  "event_id": "evt-001",
  "event_type": "vp.action.event.v1",
  "schema_version": 1,
  "session_id": "session-001",
  "sequence": 1001,
  "occurred_at_ns": 1790000000000000000,
  "producer": "action-engine",
  "trace_id": "trace-001",
  "payload": {}
}
#+END_SRC

保证:

- 同一 session 尽量按 key 分区.
- consumer 幂等.
- at-least-once 可接受.
- 业务层不依赖 exactly-once 幻觉.

* 18. 错误码

前缀:

#+BEGIN_SRC text
VP_AUTH_xxxx
VP_CAMERA_xxxx
VP_CALIB_xxxx
VP_SESSION_xxxx
VP_MODEL_xxxx
VP_RULE_xxxx
VP_STORAGE_xxxx
VP_EVIDENCE_xxxx
#+END_SRC

示例:

| code | 含义 |
| VP_CAMERA_1001 | 摄像头离线 |
| VP_CALIB_2001 | 标定配置无效 |
| VP_SESSION_3001 | 会话状态不允许此操作 |
| VP_MODEL_4001 | 模型未就绪 |
| VP_RULE_5001 | 规则校验失败 |
| VP_STORAGE_6001 | 证据存储不可用 |

- invalid state transition.

- WebSocket reconnect.
- event sequence gap.
