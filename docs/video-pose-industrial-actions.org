* 1. 首批工业动作

当前可解释 baseline:

- PICK.
- PLACE.
- ENTER_ZONE.
- LEAVE_ZONE.
- OPERATE_TOOL.
- INSPECT.

* 2. OPERATE_TOOL

#+BEGIN_SRC text
tool HELD_BY hand
AND tool IN operation_zone
AND accumulated 3D path >= threshold
THEN OPERATE_TOOL
#+END_SRC

* 3. INSPECT

使用 Zone Dwell baseline.

例如 nose/head keypoint 在 inspection_zone 连续 N 帧:

#+BEGIN_SRC text
nose IN inspection_zone
        |
stable N frames
        |
INSPECT
#+END_SRC

后续可以升级为:

- head pose.
- gaze estimation.
- inspection device state.
- multimodal temporal model.

* 4. Zone Transition

Zone Builder 支持:

- OBJECT.
- PERSON.
- BODY_KEYPOINT.

因此可以生成:

- ENTER_ZONE.
- LEAVE_ZONE.

适合安全区和禁止区域规则.

* 5. CompositeActionRecognizer

各 recognizer 的局部 event sequence 会重新排序和全局编号, 保证 Rule Engine 的事件流一致.
