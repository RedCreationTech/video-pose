* 1. 在线主链路

#+BEGIN_SRC text
4 x RTSP
  |
ThreadedLiveGateway
  |
LiveFrameSynchronizer
  |
SynchronizedFrameSet
  |
VideoPosePipeline
  |
ActionEvent
  |
RealtimeRuleSession
  |
Step Delta / Violation Delta / Score
#+END_SRC

离线 Replay 和在线 RTSP 从 SynchronizedFrameSet 开始完全复用同一条链路.

* 2. 内存帧

实时像素保存到有上限的 MemoryFrameStore:

#+BEGIN_SRC text
memory://camera-id/sequence
#+END_SRC

MemoryFrameStore 和 LiveFrameSynchronizer 均支持多摄像头线程并发.

* 3. 断流恢复

OpenCVLiveCamera.read 失败时:

- close 当前 capture.
- 等待短暂退避.
- 下一次 read 自动重新 open.

后续生产版本建议替换为 GStreamer 状态机并加入指数退避.

* 4. 实时规则

有动作:

#+BEGIN_SRC text
RealtimeRuleSession.ingest(ActionEvent)
#+END_SRC

没有动作:

#+BEGIN_SRC text
RealtimeRuleSession.tick(now_ms)
#+END_SRC

因此超时不依赖新动作才能触发.

停止 Session:

#+BEGIN_SRC text
RealtimeRuleSession.finish(session_end_ms)
#+END_SRC

执行最终 Missing 检查.

* 5. CLI

#+BEGIN_SRC sh
video-pose-live --config configs/live-demo.yaml
#+END_SRC

stdout 按 JSONL 输出:

- timestamp.
- actions.
- new violations.
- changed steps.
