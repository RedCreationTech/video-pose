* 环境检查

#+BEGIN_SRC sh
video-pose-doctor --config configs/offline-demo.yaml
#+END_SRC

* 平面标定

#+BEGIN_SRC sh
video-pose-calibrate \
  --input fixtures/calibration/front-correspondences.yaml \
  --output front-calibration.yaml
#+END_SRC

* 四路离线分析

#+BEGIN_SRC sh
video-pose-analyze \
  --config configs/offline-demo.yaml \
  --output result.json \
  --evidence-dir output/evidence
#+END_SRC

* Golden Replay

#+BEGIN_SRC sh
video-pose-evaluate \
  --dataset datasets/golden-v1/manifest.yaml
#+END_SRC

datasets/golden-v1/
#+END_SRC

* 安装

核心开发:

#+BEGIN_SRC sh
pip install -e '.[dev]'
#+END_SRC

现场离线视频 + YOLO:

#+BEGIN_SRC sh
pip install -e '.[dev,video,yolo]'
#+END_SRC

MMPose/MMCV/PyTorch/CUDA 必须按目标 GPU 环境固定版本.
