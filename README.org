* 核心设计原则

- AI 识别事实, Rule Engine 决定合规.
- 四路摄像头共享时间轴.
- Persistent Camera/Model 跨 Session 常驻.
- Session 内 Rule/Action state 独立.
- SYSTEM_QUALITY 可以直接让最终结果 FAIL.
- Immutable Audit 是灾难恢复事实源.
- PostgreSQL 是可重建 Query Store.
- 正式 Session 通过 Readiness Gate 后才允许启动.
- Evidence, Review, Audit, Reconciliation 和 Crash Recovery 都属于业务闭环.

* 安全

- Bearer Token 只配置 SHA-256 digest.
- RBAC 分离 Session, Evidence, Review, Persistence Repair.
- Camera catalog 不输出 RTSP URI.
- Docker non-root.
- read-only root filesystem.
- cap_drop ALL.
- no-new-privileges.
- HTTP 默认仅绑定 localhost, 生产放在 TLS reverse proxy 后.

- 完成现场 Go/No-Go.


* Edge Web Console

Managed service now includes a zero-build on-device operations console:

#+BEGIN_SRC text
/console
#+END_SRC

The Console covers:

- Bearer Token connection and RBAC.
- four-camera health and authenticated snapshots.
- Session Readiness.
- Session start/stop/abort.
- current evaluation, Steps and Violations.
- runtime resource health.
- Release Identity.
- Persistence/Reconciliation.
- Pending Review confirm/dismiss.

The token stays in page memory and is sent in the Authorization header. It is not stored in localStorage or placed in URLs.


* Web Console 0.52

The Edge Console now also supports:

- latest Session history.
- full Session result inspection.
- Evidence Explorer with one authenticated preview per camera.
- incomplete Audit Session listing.
- controlled ABORTED crash recovery for authorized engineers/admins.

Evidence images still use authenticated fetch + Blob URLs, so bearer tokens never appear in image URLs.
