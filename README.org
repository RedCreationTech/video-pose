* 安装

核心开发:

#+BEGIN_SRC sh
pip install -e '.[dev]'
#+END_SRC

离线视频 + YOLO:

#+BEGIN_SRC sh
pip install -e '.[dev,video,yolo]'
#+END_SRC

MMPose 需要根据目标 PyTorch/CUDA 环境安装兼容 MMCV.

系统还需要:

- ffprobe, 用于真实帧时间戳.
- ffmpeg, 用于违规证据裁剪和多视角合成.

* 离线真实视频分析

#+BEGIN_SRC sh
video-pose-analyze \
  --config configs/offline-demo.yaml \
  --output result.json
#+END_SRC

同时生成违规证据:

#+BEGIN_SRC sh
video-pose-analyze \
  --config configs/offline-demo.yaml \
  --output result.json \
  --evidence-dir output/evidence
#+END_SRC

证据目录示例:
