* 实时服务

安装:

#+BEGIN_SRC sh
pip install -e '.[api,video,yolo]'
#+END_SRC

启动:

#+BEGIN_SRC sh
video-pose-serve \
  --config configs/offline-demo.yaml \
  --host 0.0.0.0 \
  --port 8080
#+END_SRC

接口:

#+BEGIN_SRC text
GET /health/live
GET /health/ready
GET /api/v1/runtime/health
GET /api/v1/runtime/latest
GET /metrics
WS  /api/v1/realtime
#+END_SRC

* 实时 CLI

#+BEGIN_SRC sh
video-pose-live \
