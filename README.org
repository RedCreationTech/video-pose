* 安装

核心开发:

#+BEGIN_SRC sh
pip install -e '.[dev]'
#+END_SRC

离线视频 + YOLO:

#+BEGIN_SRC sh
pip install -e '.[dev,video,yolo]'
#+END_SRC

MMPose:

#+BEGIN_SRC sh
pip install -e '.[mmpose]'
#+END_SRC

MMPose/MMCV/PyTorch/CUDA 的版本必须按照目标 GPU 环境固定, 生产部署不建议
依赖 pip 自动猜测 CUDA 组合.
