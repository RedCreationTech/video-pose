* 安装

核心开发:

#+BEGIN_SRC sh
pip install -e '.[dev]'
#+END_SRC

离线视频 + YOLO:

#+BEGIN_SRC sh
pip install -e '.[dev,video,yolo]'
#+END_SRC

MMPose 需要根据目标 PyTorch/CUDA 环境安装兼容 MMCV.

* 离线真实视频分析

配置入口:

#+BEGIN_SRC text
configs/offline-demo.yaml
#+END_SRC

准备:

- 四路录像.
- YOLO 工具/工件权重.
- RTMPose config/checkpoint.
- calibration.
- zones.
- rules.

执行:

#+BEGIN_SRC sh
video-pose-analyze \
  --config configs/offline-demo.yaml \
  --output result.json
#+END_SRC

只跑少量同步帧做环境检查:

#+BEGIN_SRC sh
video-pose-analyze \
  --config configs/offline-demo.yaml \
  --max-frame-sets 100
#+END_SRC

退出码:

- 0: 有评估结果且通过.
- 2: 有评估结果但不通过.
- 3: 没有产生可评估动作.
