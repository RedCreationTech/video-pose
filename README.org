当前代码已经形成三层可执行闭环:

#+BEGIN_SRC text
4-View Video Timeline
   |
Synchronized FrameSet
   |
PerceptionAdapter
   |
Observation
   |
Semantic Fusion
   |
Explainable Action Baseline
   |
ActionEvent
   |

   |

真实 AI 模型被限制在 =PerceptionAdapter= 边界. YOLO, RTMPose, 手部模型或远程
推理服务都可以替换, 而 Observation, ActionEvent 和 Rule Engine 契约保持稳定.

* 四路录像 Manifest

=ReplayPlanner= 使用 ffprobe 获取真实帧时间戳, 应用每个摄像头的时钟修正值,
然后根据 =sync_tolerance_ms= 生成四路同步 FrameSet.

#+BEGIN_SRC python
from video_pose.video_replay import ReplayPlanner

planner = ReplayPlanner.from_manifest_file(
    "fixtures/replay/session-manifest.yaml"
)
frame_sets = planner.plan()
#+END_SRC

Manifest 中的 =clock_offset_ms= 定义为需要加到源时间戳上的校正量.

* Observation Replay

#+BEGIN_SRC python
from video_pose.observation_replay import run_observation_replay

result = run_observation_replay(
    "fixtures/observations/pick-place-compliant.jsonl",
    "fixtures/rules/pick-place.yaml",
)
print(result.model_dump_json(indent=2))
#+END_SRC

PICK/PLACE recognizer 是可解释 baseline. 后续 Temporal Model 只需要产出相同
=ActionEvent= 契约, 不需要改写 Rule Engine.
