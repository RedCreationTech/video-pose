#+BEGIN_SRC text

   |

   |

Level B

   |
Semantic Fusion
   |

   |

   |
Rule Engine

  --rules fixtures/rules/assembly-a.yaml

* Observation Replay

#+BEGIN_SRC sh
python - <<'PY2'
from video_pose.observation_replay import run_observation_replay

result = run_observation_replay(
    "fixtures/observations/pick-place-compliant.jsonl",
    "fixtures/rules/pick-place.yaml",
)
print(result.model_dump_json(indent=2))
PY2
#+END_SRC

这里的 PICK/PLACE recognizer 是可解释 baseline. 后续 Temporal Model, YOLO 和 RTMPose
只需要产出相同 Observation/ActionEvent 契约, 不需要改写 Rule Engine.
